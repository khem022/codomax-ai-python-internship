# Module 2 Learning Notes - Python Mini Project

## Project
Python Expense Tracker

## Objective
Build a command-line application that records, displays, summarizes, and deletes personal expenses.

## Python concepts applied
1. Variables and data types
2. Input and output
3. if/elif/else
4. for and while loops
5. Lists
6. Dictionaries
7. Functions
8. Exception handling
9. JSON file handling
10. datetime

## Main functions
- `load_expenses()` loads saved data.
- `save_expenses()` stores data in JSON.
- `add_expense()` records a new expense.
- `view_expenses()` displays expenses.
- `show_total()` calculates total spending.
- `category_summary()` groups spending by category.
- `delete_expense()` removes a selected expense.
- `show_menu()` displays the menu.
- `main()` controls the application.

## How to test
Test adding multiple expenses, viewing them, calculating the total, checking category totals, deleting an expense, closing the program, and reopening it to confirm that the JSON data is preserved.

## Learning outcome
The project demonstrates how Python fundamentals can be combined to create a useful real-world beginner application.
