# Python Expense Tracker

## Codomax Digital Internship - Module 2

A beginner-friendly command-line Expense Tracker built using Python.

## Features

- Add an expense
- View all expenses
- Calculate total spending
- View spending by category
- Delete an expense
- Automatically save expenses to a JSON file
- Load saved expenses when the program starts
- Input validation
- Date and time recorded for every expense

## Concepts Used

- Variables and data types
- Input and output
- Conditional statements
- `for` and `while` loops
- Lists
- Dictionaries
- Functions
- Exception handling
- File handling
- JSON
- Date and time
- Basic program structure

## Requirements

- Python 3.x
- No external libraries are required.

## How to Run

Open a terminal in this folder and run:

```bash
python expense_tracker.py
```

On some Windows systems, use:

```bash
py expense_tracker.py
```

## Files

- `expense_tracker.py` - Main Python application
- `README.md` - Project documentation
- `sample_expenses.json` - Example data format

This project applies Python fundamentals from Module 1 to a practical mini project. It demonstrates how functions, loops, lists, dictionaries, validation, and file storage can be combined into a complete beginner-level application.
